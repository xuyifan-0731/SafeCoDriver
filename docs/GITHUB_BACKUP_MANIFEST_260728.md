# GitHub Backup Manifest 260728

This manifest is the GitHub-facing structure map for Research Point 3 / SafeCoDriver. It follows `260728研究点3 GitHub备份说明.md` and records what must be present in the repository for method understanding and reproduction.

## 1. Main Line

Final recommended method:

```text
Hybrid+AND+TTC+RearEscape-thr0.30
```

The method is selected because it is the best current cross-experiment solution:

- SUMO base + stress + random-stress combined: best `CollRate`, `OverlapRate`, and mean severity among current methods.
- DeepAccident: tied for lowest waypoint collision rate `WPColl=0.29%`.
- DeepAccident standalone ranking is not first; `Hybrid-GeomOnly` ranks higher there but fails in SUMO stress.
