# 260728 SafeCoDriver Experiment Reproduction Guide

This document is the GitHub-facing reproduction guide for Research Point 3.
It is written so that another machine, or another ChatGPT instance with access
to the GitHub repository, can recover the required files, run the experiments,
and compare the reproduced outputs with the backed-up results.

Main reference document:

```text
260728研究点3 GitHub备份说明.md
```

Main recommended cross-experiment method:

```text
Hybrid+AND+TTC+RearEscape-thr0.30
```

Strict interpretation: this method is the best current cross-experiment choice
because it has the lowest combined SUMO `CollRate`, `OverlapRate`, and average
per-run severity, while tying the Hybrid family's lowest DeepAccident waypoint
collision rate. It is not DeepAccident ranking #1; DeepAccident ranking #1 is
`Hybrid-GeomOnly`.

## 2. Environment

Recommended environment:

```bash
conda create -n coop-safety python=3.10 -y
conda activate coop-safety

pip install torch==2.5.1 torchvision --index-url https://download.pytorch.org/whl/cu121
pip install numpy scipy shapely scikit-learn pandas matplotlib

```

If `eclipse-sumo` does not provide a working `sumo` binary on the target
machine, install SUMO through the system package manager and ensure `sumo` is
available in `PATH`. The current scripts set `SUMO_HOME` from the active Python
environment:

```text
<conda-env>/lib/python3.10/site-packages/sumo
```

## 3. Data And Checkpoint Recovery

### 3.1 DeepAccident

Restore the DeepAccident validation data into:



`models/collision_net_best.pt`, not a random split generated at runtime.

### 3.2 SUMO

SUMO network XML files are tracked under:

```text
experiments/sumo_scenarios/networks/
```

The `BS*.rou.xml`, `*_stress.rou.xml`, and `*_rand42.rou.xml` route files are
generated by the code when SUMO evaluation runs:

- base routes: `experiments/gen_scenario_gifs.py`
- stress routes: `inject_rear_attacker()` in `experiments/run_modified_sumo_comparison.py`
- random-stress routes: `inject_random_stress()` in `experiments/run_modified_sumo_comparison.py`

These route files are generated artifacts and do not need to be committed.

```bash
PY
```

SUMO combined ranking from reproduced outputs:

```bash
python - <<'PY'
import csv
from collections import defaultdict

files = [
    "results/reproduce_sumo_base_260728/per_run.csv",
    "results/reproduce_sumo_stress_260728/per_run.csv",
    "results/reproduce_sumo_random_stress_260728/per_run.csv",
]
agg = defaultdict(lambda: {"n": 0, "coll": 0, "overlap": 0, "sev": 0.0, "wp": 0.0, "total": 0.0})
for path in files:
    with open(path, newline="") as f:
        for row in csv.DictReader(f):
            m = row["method"]
            agg[m]["n"] += 1
            agg[m]["coll"] += int(row["collision"])
            agg[m]["overlap"] += int(row["overlap"])
            agg[m]["sev"] += float(row["severity"])
            agg[m]["wp"] += float(row["wp_coll"])
            agg[m]["total"] += float(row["wp_total"])

for method, a in sorted(
    agg.items(),
    key=lambda item: (
        item[1]["coll"] / item[1]["n"],
        item[1]["overlap"] / item[1]["n"],
        item[1]["sev"] / item[1]["n"],
    ),
):
    print(
        f"{method}: n={a['n']}, "
        f"CollRate={a['coll']/a['n']:.6f}, "
        f"OverlapRate={a['overlap']/a['n']:.6f}, "
        f"AvgSev={a['sev']/a['n']:.6f}, "
        f"WPC={a['wp']/max(a['total'], 1):.6f}"
    )
PY
```

## 8. Troubleshooting

If Python reports `ModuleNotFoundError: No module named 'torch'`, activate the
correct conda environment or reinstall PyTorch.

If Python reports `ModuleNotFoundError: No module named 'traci'`, reinstall
SUMO Python bindings:

```bash
pip install eclipse-sumo traci sumolib
```

If SUMO starts but no vehicles move, check that the network XML files exist
under `experiments/sumo_scenarios/networks/` and rerun the SUMO command. The
route XML files are regenerated at runtime.

If DeepAccident evaluation cannot find scenarios, check that the four expected
DeepAccident directories exist directly under `data/DeepAccident/`.

If reproduced numbers differ slightly in SUMO, first compare `metadata.json`,
SUMO version, random seed, and the generated `per_run.csv`. The seed-42
random-stress command above is the backed-up reference setting.
